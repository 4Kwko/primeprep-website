# Referências de Social Media

Este diretório guarda as **peças gráficas originais** da Prime Prep enviadas pelo cliente.

## Natureza

São **referência de identidade visual**, não assets de produção. Informam paleta, tipografia, ornamento e composição — não viram imagem do site.

Por isso ficam aqui, **fora de `public/`**: assim é impossível publicá-las por acidente. Ver `docs/setup/assets.md` (D-13 em `setup-decisions.md`).

## Peças analisadas

1. **Cartão institucional** — logo (águia + livro + wordmark) sobre navy, moldura ornamental completa
2. **Cartão de contato** — João Montagner, WhatsApp/Instagram/e-mail, QR code, águia em marca d'água
3. **Carrossel "Você quer ser militar?"** — EFOMM, EEAR, AFA, EsPCEx + tabela comparativa
4. **Peça do chatbot** — dourado como acento, textura de linho, CTA outline, divisor com losango

Análise completa em [`../../planning/visual-identity-analysis.md`](../../planning/visual-identity-analysis.md).
